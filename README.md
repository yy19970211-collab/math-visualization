# 交互单元(Demo)

全部为本地 HTML,双击即开,离线运行(Three.js 已下载到本地,不依赖外网)。

## 已建成单元

| 单元 | 文件 | 内容 | 核心演示点 |
|---|---|---|---|
| 莫比乌斯带 | `demo/index.html` | 不可定向曲面 | 法向箭头沿中心线走一圈,回到起点方向反转;半扭转数 0/1/2 对比 |
| 和乐性 | `demo/holonomy.html` | 微分几何·平行移动 | 测地三角形/纬线圈两种路径,和乐角 = 角盈(数值实时校验);轨迹快照(每 5% 一个箭头) |
| 全局高斯博内公式 | `demo/ggb/index.html` | 微分几何·证明流程(5 幕) | ① 球面角盈(θ/自由选点+面积S) ② 角盈可加性(细分至256+自由选点) ③ 勒让德证明(三种正多面体吹胀到球面) ④ 加手柄三步走(拆开/贴合/构成) ⑤ 全局定理 ∫∫K=2πχ(水滴形/环面剖分+5步证明) |

## 说明

- 统一使用中国古典配色:玄青(背景)/ 石青(曲面)/ 藤黄(路径)/ 朱砂(主对象)/ 缃色(快照)/ 月白(初始方向)。
- 每个单元右下角有"理论值 vs 测得值"校验(checkpoint),防止可视化数字出错。
- 单元配置 DSL 规范见 `docs/dsl-spec.md`。
